# Traffic Dodge · Highway Crossing

Free single-file HTML5 arcade game. Frogger-style road crossing: dodge
12 lanes of traffic, chain lane crossings for combo bonuses, and reach
the top grass to start a faster round. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/traffic-dodge/

- Arrows / WASD on desktop, swipe or tap an adjacent tile on mobile
- Random lanes: direction, 3 speed tiers, gaps, police cars and 2-cell trucks
- +1 per new lane, +5 per round, combo bonus (+combo x 0.5), 3 lives with
  1.5s spawn shield, best score saved locally
- Night mode with glowing headlights once you pass 30 points
- Procedural graphics & WebAudio sounds, no dependencies, no tracking
